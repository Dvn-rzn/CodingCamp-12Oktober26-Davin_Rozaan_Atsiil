# Project: Personal Dashboard

## Tech Stack
- HTML, CSS, Vanilla JavaScript
- No frameworks, no backend
- Browser LocalStorage for data persistence

## Folder Structure
```
index.html       ← main page
css/style.css    ← single CSS file
js/app.js        ← single JS file
.kiro/           ← Kiro IDE configuration
```

## Features
- Greeting with live clock and date
- Focus Timer (Pomodoro) with customizable duration
- To-Do List with add / edit / delete / done / sort / duplicate prevention
- Quick Links saved to LocalStorage
- Light / Dark mode toggle
- Custom name in greeting

## Coding Standards
- Use vanilla JS only, no frameworks
- Keep all JS in js/app.js
- Keep all CSS in css/style.css
- Use localStorage keys prefixed with `db_`
